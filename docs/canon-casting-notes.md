# 《雷索纳斯：列车长的一日》原作设定与出场角色修订

## 结论

此前 `story-script.md` 使用了“阿莉娅 / 米卡 / 诺艾尔”等原创占位角色，不适合继续作为《雷索纳斯》明确同人项目的剧情基础。后续台本必须改用原作乘员、原作势力、原作站点，并把不确定内容明确标为“同人推断”。

第一版互动核心建议固定为：

- 主互动角色：莉薇娅
- 次核心互动角色：遥、波克士
- 常驻支援角色：弗兰、艾略特
- 分站点登场角色：妮蔻拉、卡洛琳、星花、静流

这样可以形成“列车内部日常 + 站点委托支线”的结构，不会脱离列车长视角。

## 已确认核心成员

### 莉薇娅

来源：https://wiki.biligame.com/resonance/莉薇娅

资料事实：

- 势力：科伦巴商会
- 现身份：科伦巴商会·列车助理
- 出身地：曼杜斯帝国
- 升构能力：能力摹写
- 特长：家务、会计、沏茶
- 喜爱：阅读、口琴、红茶
- 厌恶：恶徒、恶意暴力行为
- 页面台词强调“就在你身边，列车长”

同人定位：

- 必须作为主要可互动角色。
- 她是玩家日常系统的“锚点”：早晚汇报、整理委托、记录乘员状态、提醒资源风险。
- 她适合承担情感主线：不是单纯秘书，而是最了解列车长每日取舍的人。
- 她的分支应围绕“列车助理是否只是协助你完成委托，还是开始主动质疑委托背后的风险”。

玩法功能：

- 会计：降低资金 / 订单结算损失。
- 沏茶与家务：恢复士气或疲劳，但占用时段。
- 能力摹写：作为关键剧情能力，不滥用；可在终盘复制一次其他乘员的行动效果。

### 弗兰

来源：https://wiki.biligame.com/resonance/弗兰

资料事实：

- 势力：科伦巴商会
- 现身份：科伦巴商会·护卫乘员
- 出身地：伊敦恩城
- 升构能力：无
- 页面台词提到“您知道艾略特在哪里吗？”
- 战斗定位：前排；技能包含盾牌撞击、能量护盾、绝对胜利。

同人定位：

- 常驻护卫角色，不一定作为第一版主互动角色，但应频繁出现在巡逻、护卫、风险事件中。
- 她和艾略特可以做成“双人支线”：一个偏正面护卫与保护，一个偏后排支援和治疗。
- 她适合承担“乘员安全 vs 任务效率”的压力线。

玩法功能：

- 降低袭击 / 高风险委托的损失。
- 能量护盾可转译为“保护乘员 / 保护货物 / 保护乘客”的选择。
- 若忽略护卫安排，高风险事件会损失补给或士气。

### 艾略特

来源：https://wiki.biligame.com/resonance/艾略特

资料事实：

- 势力：科伦巴商会
- 现身份：科伦巴商会·护卫乘员
- 出身地：伊敦恩城
- 升构能力：无
- 页面台词：“该干的活我会干的。”
- 战斗定位：后排；技能包含强愈弹、爆炎弹、飞电弹。

同人定位：

- 常驻支援角色，与弗兰形成护卫组。
- 她适合做“少话但可靠”的任务执行者，支线不必过度煽情。
- 她可以把资源管理具体化：治疗弹药、爆炎弹风险、远程支援都需要物资。

玩法功能：

- “强愈弹”转译为医疗 / 急救资源，消耗补给但避免乘员受伤。
- “爆炎弹”可处理道路障碍，但提高风险或损伤车况。
- 与弗兰同时派出时，安全收益高，但列车内人手不足。

### 遥

来源：https://wiki.biligame.com/resonance/遥

资料事实：

- 势力：科伦巴商会
- 现身份：科伦巴商会·维修师
- 出身地：贡露城
- 升构能力：无
- 页面台词：“维修有我，你只管做好你的事就行。”
- 战斗 / 技能文本带有爆炸物、点燃、抽高费牌等要素。

同人定位：

- 建议作为次核心互动角色。
- 她是列车状态系统的负责人：车况、引擎、车厢、路线故障都应通过她的报告呈现。
- 性格可从资料台词推断为干脆、少废话、专业优先。

玩法功能：

- 修复车况，降低故障概率。
- 改造列车可提高效率，但会消耗零件、燃料或增加事故风险。
- 若玩家长期不找遥维护，后续强制停驶或失去路线选项。

### 波克士

来源：https://wiki.biligame.com/resonance/波克士

资料事实：

- 势力：科伦巴商会
- 现身份：科伦巴商会·行车助理
- 性别：无
- 身高：47cm
- 出身地：科伦巴商会
- 页面台词：仿生技工十代启动，要求选择仿生对话系统声纹。
- 技能包含军械库、饮品速递、自我报废；饮品中包含“莉薇娅特殊配方的红茶”。

同人定位：

- 建议作为次核心互动角色 / 系统吉祥物。
- 它适合承担 UI 提示、系统播报、轻喜剧缓冲、资源转换。
- 波克士和莉薇娅有天然互动点：红茶、列车助理、行车支援。

玩法功能：

- 饮品速递：恢复疲劳 / 士气，但可能随机。
- 军械库：临时解决突发风险，但会消耗弹药或提高风险。
- 自我报废：极端选择，用波克士损坏换一次危机解除，之后需要修复。

## 站点与剧情适配

### 起点：列车内部 / 科伦巴商会委托

核心角色：

- 莉薇娅
- 遥
- 波克士
- 弗兰
- 艾略特

故事功能：

- 列车长从科伦巴商会接到短途委托。
- 莉薇娅负责订单与行程。
- 遥负责车况。
- 波克士负责行车提示与杂务。
- 弗兰 / 艾略特负责护卫。

### 7号自由港

资料事实来源：https://wiki.biligame.com/resonance/7号自由港

资料要点：

- 核心城市。
- 临界之后在原自由港遗址附近重建。
- 受形态污染影响，气候诡异多变，也形成特殊风光和地貌。
- 附属城市包括阿妮塔能源研究所。

适合剧情：

- 第一章或第二章外部站点。
- 适合做“天气 / 路线 / 形态污染导致延误”的主线压力。
- 卡洛琳可在这里登场。

### 阿妮塔能源研究所

资料事实来源：https://wiki.biligame.com/resonance/阿妮塔能源研究所

资料要点：

- 阿妮塔下属能源研究站点。
- 具备将桦石和桦树生物能量转化为电力的成熟技术。
- 与 7号自由港合作紧密。

适合剧情：

- 能源危机线。
- 遥与妮蔻拉的技术合作 / 分歧。
- 可让玩家在“拿能源稳定列车”与“保留样本完成委托”之间取舍。

### 修格里城 / 铁盟哨站

资料事实来源：

- https://wiki.biligame.com/resonance/修格里城
- https://wiki.biligame.com/resonance/铁盟哨站

资料要点：

- 修格里城拥有 8 座现实稳定装置，矿产丰富、制造业发达。
- 铁盟哨站前身是修格里城建设现实稳定装置时设立的物资转运站，后发展为防卫修格里的军事哨站。

适合剧情：

- 中后段危机节点。
- 静流登场，代表铁盟规程与军事封锁。
- 可做“准点交货 vs 接受铁盟检查导致延误”的资源管理分支。

## 建议的新主线方向

标题暂定：`下一站，风暴边界`

主线不再使用原创“密封货箱 / 雾灯”设定，而改成更贴近原作结构：

> 科伦巴商会安排列车长从 7号自由港接一批能源转换部件，送往修格里城用于现实稳定装置维护。途中形态污染导致线路异常，阿妮塔能源研究所请求列车临时改道取回桦石转化样本；铁盟哨站则要求列车按规程停靠检查。列车长必须在准点、能源、车况、商会信用、乘员疲劳之间取舍。

这条主线的好处：

- 保留原作跑商 / 站点 / 列车委托味道。
- 但小游戏核心不是跑商，而是列车内的乘员互动与资源调度。
- 莉薇娅可作为全程陪伴角色，不会被站点 NPC 抢走主位。
- 遥、波克士、弗兰、艾略特都有清晰职责。
- 卡洛琳、妮蔻拉、静流可以按站点自然登场。

## 第一版互动角色分层

### 强互动

- 莉薇娅：每天早晚都能互动；决定商会信用、士气、隐藏结局。
- 遥：维修 / 车况核心；决定能否赶路、改道、撑过污染天气。
- 波克士：行车助手 / 随机应急；决定轻喜剧节奏和部分资源转换。

### 中互动

- 弗兰：护卫、检查货物、应对袭击。
- 艾略特：治疗、后排支援、处理受伤乘客。

### 站点互动

- 卡洛琳：7号自由港 / 路线侦查。
- 妮蔻拉：阿妮塔能源研究所 / 能源与技术方案。
- 静流：铁盟哨站 / 规程与封锁。
- 星花：阿妮塔支线 / 士气与研究协助，可放第二版。

## 后续改写原则

1. 所有角色名必须来自《雷索纳斯》资料。
2. 角色身份、出身、势力、能力不可凭空改写。
3. 具体情节可以同人原创，但必须围绕原作站点、势力、列车长职责展开。
4. 不确定内容必须标注为“同人推断”。
5. 第一版不要塞太多乘员，宁可让少数角色有完整互动循环。
