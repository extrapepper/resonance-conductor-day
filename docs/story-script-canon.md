# 《雷索纳斯：列车长的一日》正典角色版台本草案

> 当前版本：三日可玩原型用。  
> 核心约束：莉薇娅为主互动角色；遥、波克士为次核心互动角色；弗兰、艾略特常驻支援；卡洛琳、妮蔻拉、静流按站点登场。  
> 写作前置：见 `docs/character-voice-guide.md`。

## 资料依据

- 莉薇娅、遥、波克士、弗兰、艾略特均为科伦巴商会相关乘员。
- 7号自由港是受形态污染影响、气候诡异多变的核心城市，阿妮塔能源研究所为其附属城市。
- 阿妮塔能源研究所拥有将桦石和桦树生物能量转化为电力的成熟技术。
- 修格里城拥有 8 座现实稳定装置，矿产资源丰富、制造业发达。
- 铁盟哨站前身与修格里城现实稳定装置建设时的物资转运有关，后来发展为防卫修格里的军事哨站。

## 主线名

`下一站，风暴边界`

## 主线一句话

科伦巴商会列车接下从 7号自由港转运阿妮塔能源研究所能源部件、送往修格里城现实稳定装置维护线的短途委托；途中形态污染引发线路异常，阿妮塔方面要求临时回收关键样本，铁盟哨站要求按规程停靠检查。列车长必须在准点、车况、燃料、商会信用、乘员疲劳与角色信任之间取舍。

## 设计目标

第一版只做 3 天，每天 3 个时段，完整形成一次“接委托 - 出异常 - 做路线选择 - 结算后日谈”的循环。

玩家不能通过全选好事拿满收益。每个关键选项都至少损失一种资源，或锁掉另一条角色事件。

核心情绪不是打败巨大敌人，而是：列车继续前进时，车上的每个人都在用自己的职责托住它；列车长的价值在于决定把有限资源交给谁、把风险留给谁。

## 核心资源

- `车况`：低于 35 时部分绕行和加速选项锁定；低于 20 触发强制维修结局。
- `燃料`：绕行、加速、污染区脱离会消耗。低燃料无法准点抵达。
- `补给`：红茶、急救、乘客安抚、维修餐食都消耗补给。不是纯医疗资源。
- `士气`：低于 35 时弗兰/艾略特不会主动承担额外护卫，乘员夜间对话减少。
- `疲劳`：高于 75 时夜晚行动只能休息或由波克士自动处理。
- `线索`：决定是否知道能源样本异常、哨站封锁原因、委托隐藏风险。
- `风险`：污染区绕行、违规赶路、隐瞒检查都会增加。高风险触发袭扰或哨站扣留。
- `商会信用`：准点、货物完整、记录清楚会上升；违约、隐瞒、损坏货物会下降。
- `莉薇娅信任`：影响结算协商、账目补救、乘员后日谈。
- `遥信任`：影响车况补救、改造路线、最终能否带伤抵达。
- `波克士稳定度`：不是好感。频繁调用应急功能会下降，过低时自动播报和饮品速递出错。

## 主要路线

### A. 准点交付线

目标：按合同把能源部件送到修格里城。  
收益：商会信用高、风险低、准点结算好。  
代价：线索较少，阿妮塔样本异常可能未处理，莉薇娅会在后日谈中提醒“有些账不是今天结清就结束”。  
适合玩家：保守、重视列车运营与委托履约。

### B. 研究所协助线

目标：改道阿妮塔能源研究所，帮助妮蔻拉回收桦石转化样本。  
收益：线索高、能源问题解释更完整、遥可获得技术方案。  
代价：燃料和时间大幅下降，商会信用承压，铁盟哨站更严格检查。  
适合玩家：重视真相与技术风险。

### C. 哨站合规线

目标：在铁盟哨站接受完整检查，获得静流协助护送。  
收益：风险下降，最终污染区损失更小。  
代价：准点压力大，补给被抽检，部分隐藏委托曝光。  
适合玩家：重视安全和秩序。

### D. 乘员优先线

目标：把乘员疲劳、士气、车况放在首位，牺牲部分委托收益。  
收益：角色后日谈最好，最终即使没准点也不会崩盘。  
代价：商会信用一般，结算奖励少。  
适合玩家：想做“列车长的一日”的日常情感路线。

## Day 1：7号自由港，出发前的账

主背景：列车驾驶室 / 餐车 / 货仓 / 7号自由港站台。  
主登场：莉薇娅、遥、波克士、弗兰、艾略特、卡洛琳。

### 上午：委托交接

剧情：
- 科伦巴商会短途委托送达。货物是阿妮塔能源研究所封装的能源转换部件，终点登记为修格里城维护线。
- 莉薇娅整理合同时发现条款很紧：准点、封条完整、污染区不得擅自停靠。
- 波克士播报天气异常：7号自由港外缘风向变化过快。
- 卡洛琳作为探路者登场，提醒“今天的路不太像地图上那条”。

可选行动：

1. `按合同直接发车`
   - 车况 0，燃料 -5，商会信用 +8，线索 0，莉薇娅信任 -2。
   - 莉薇娅会记录条款，但提醒列车长别把“没有异常”当成“没有风险”。

2. `让莉薇娅复核委托账目`
   - 时间压力 +1，商会信用 +3，线索 +1，莉薇娅信任 +6，疲劳 +4。
   - 解锁夜晚“账本夹页”事件。

3. `听取卡洛琳的绕行建议`
   - 燃料 -10，风险 -8，准点 -1，线索 +1。
   - 若拒绝卡洛琳，Day 2 污染区会多一次随机车况损失。

示例对白：
- 莉薇娅：“合同没有问题，但太干净了。干净到像是有人替我们擦掉了该看的部分。”
- 遥：“发车可以。后面会响。”
- 波克士：“哔哔！签字前建议列车长摄入液体。红茶、清水，或承认自己紧张的勇气。”

### 下午：发车检查

剧情：
- 遥发现车底传感器对货仓封装箱有轻微干扰。
- 弗兰和艾略特申请重新安排护卫站位。
- 玩家必须在车况、护卫、乘员士气之间选一个重点。

可选行动：

1. `让遥拆检传感器`
   - 车况 +8，线索 +1，准点 -1，遥信任 +6。
   - 若上午未复核账目，莉薇娅信任 -2，因为记录不完整。

2. `安排弗兰和艾略特护卫货仓`
   - 风险 -8，士气 +4，补给 -3，线索 0。
   - 解锁夜晚护卫搭档小事件。

3. `让波克士完成快速发车流程`
   - 准点 +1，波克士稳定度 -8，车况 -4。
   - 若连续两次依赖波克士应急，Day 2 饮品速递可能出错。

示例对白：
- 弗兰：“货仓到餐车之间人最多。我在前段，艾略特在后段。”
- 艾略特：“后段？那里离餐车最远吧？我能申请一个更有人情味的站位吗？”
- 弗兰：“不能。站岗。”
- 遥：“快，还是稳。选。”

### 夜晚：第一段异常播报

剧情：
- 列车驶离 7号自由港外缘，收到一段阿妮塔格式的低频回传。
- 波克士无法完整解码，只能判定与货物批次有关。
- 莉薇娅泡好红茶，把未签字的附页放到列车长面前：货物保险条款里有一段被折过。

可选行动：

1. `和莉薇娅核对附页`
   - 线索 +2，莉薇娅信任 +8，疲劳 +6。
   - 莉薇娅发现：若货物因污染区异常失效，责任会转嫁给承运列车。

2. `去货仓询问遥`
   - 车况 +4，遥信任 +6，疲劳 +8，莉薇娅信任 +1。
   - 遥确认货物不是普通备用部件，可能自带低功率响应。

3. `让波克士自动解码，列车长休息`
   - 疲劳 -10，波克士稳定度 -10，线索 +1。
   - 若稳定度低于 70，次日早晨会误判一条风险提示。

Day 1 结尾钩子：
> 货仓深处响起极轻的一声回音。不是撞击，更像有人在封装箱里敲了一下杯壁。

## Day 2：阿妮塔能源研究所，样本与功率

主背景：行驶中的驾驶室 / 阿妮塔能源研究所外部接驳区 / 维修车厢。  
主登场：莉薇娅、遥、波克士、妮蔻拉；弗兰/艾略特根据风险登场。

### 上午：研究所请求

剧情：
- 妮蔻拉发来临时通讯，要求列车停靠阿妮塔能源研究所接驳区，回收一份桦石转化样本校准数据。
- 合同不允许擅自停靠，但如果不校准，货物在污染区可能过载。
- 莉薇娅指出：停靠会影响商会信用，但拒绝可能导致更大赔付。

可选行动：

1. `拒绝停靠，维持原路线`
   - 准点 +1，商会信用 +5，线索 -1，风险 +6，莉薇娅信任 -2。
   - Day 3 进入哨站时更难解释异常读数。

2. `短暂停靠，只接收数据`
   - 准点 -1，线索 +2，燃料 -5，商会信用 -3。
   - 解锁妮蔻拉远程技术建议。

3. `完整停靠，协助回收样本`
   - 准点 -2，燃料 -10，线索 +3，遥信任 +5，商会信用 -8。
   - 若车况低于 40，离站时触发一次额外故障。

示例对白：
- 妮蔻拉：“我不建议你把这称为请求。它更接近一次避免损失扩大的机会。”
- 莉薇娅：“列车长，我可以把停靠写成风险规避，但账面上的时间不会因此变短。”
- 遥：“数据没错。继续发热，车底先坏。”

### 下午：功率分配

剧情：
- 研究所数据证明封装部件与列车电力系统存在异常耦合。
- 遥提出加装临时旁路，波克士提出降低舒适车厢供电，莉薇娅提醒乘客士气会受影响。

可选行动：

1. `让遥加装旁路稳定器`
   - 车况 +10，补给 -5，疲劳 +8，遥信任 +8。
   - 若上午完整停靠，额外获得线索 +1。

2. `让波克士限制非必要供电`
   - 燃料 +5，士气 -8，波克士稳定度 -4。
   - 莉薇娅会建议夜晚安抚乘员。

3. `保持乘客舒适，承受功率波动`
   - 士气 +6，车况 -10，风险 +5，莉薇娅信任 +2。
   - 如果车况低于 35，Day 3 上午强制维修。

示例对白：
- 波克士：“哔哔！当前方案会降低餐车照明、座椅加热，以及半吊子列车长装作没事的成功率。”
- 莉薇娅：“大家可以忍受一点不方便，但他们需要知道为什么。”
- 遥：“一个时段。能用。”

### 夜晚：红茶与广播

剧情：
- 乘员疲劳上升。莉薇娅在餐车给乘员准备红茶，波克士协助饮品速递。
- 若白天牺牲士气或补给，夜晚必须选择安抚、修车、解码三者之一。

可选行动：

1. `陪莉薇娅安抚乘员`
   - 士气 +12，莉薇娅信任 +8，线索 0，疲劳 +4。
   - 弗兰/艾略特在 Day 3 可主动承担一次护卫风险。

2. `继续和遥排查车底噪音`
   - 车况 +6，线索 +1，遥信任 +5，士气 -4，疲劳 +10。

3. `让波克士接管广播`
   - 士气 +4，波克士稳定度 -8，疲劳 -4。
   - 若稳定度低于 60，播报会夹入异常噪声，风险 +4。

Day 2 结尾钩子：
> 广播结束后，波克士停顿了两秒。随后它用没有选择过的声纹说：下一站，请勿相信窗外的站牌。

## Day 3：铁盟哨站，规程与抵达

主背景：铁盟哨站检查线 / 驾驶室 / 污染区边界 / 修格里城远景。  
主登场：莉薇娅、遥、波克士、弗兰、艾略特、静流。

### 上午：哨站拦检

剧情：
- 列车抵达铁盟哨站外围。静流要求停车检查，理由是沿线污染指数与列车封装货物读数不匹配。
- 如果前两日线索高，玩家可解释异常；如果线索低，只能按流程接受检查或硬闯风险区。

可选行动：

1. `接受完整检查`
   - 准点 -2，风险 -12，商会信用 -4，线索 +1。
   - 静流后续可提供护送许可。

2. `提交莉薇娅整理的风险记录，申请快速通行`
   - 条件：莉薇娅信任 >= 14 或线索 >= 4。
   - 准点 -1，风险 -6，商会信用 +2，莉薇娅信任 +4。

3. `拒绝检查，绕开哨站`
   - 燃料 -15，风险 +18，商会信用 -12，准点 +1。
   - 弗兰/艾略特必须消耗护卫资源抵消一次袭扰。

示例对白：
- 静流：“我可以给你解释的时间，但不能替你省略规程。”
- 莉薇娅：“记录我都带来了。列车长，接下来要看你愿不愿意把真相写进交接单。”
- 弗兰：“如果必须绕开，我和艾略特去后段。”
- 艾略特：“为什么又是后段……好好好，我知道了，别这么看我。”

### 下午：污染区边界

剧情：
- 无论是否通过哨站，列车都会进入形态污染影响的边界地带。
- 货物读数升高，车况、燃料、士气进入最终压力测试。

可选行动：

1. `加速穿越`
   - 条件：燃料 >= 20，车况 >= 35。
   - 准点 +2，燃料 -20，车况 -10，疲劳 +10。
   - 若遥信任高，可把车况损失降为 -5。

2. `低速稳定穿越`
   - 准点 -1，风险 -8，车况 -4，士气 -4。
   - 若士气低于 35，触发乘客恐慌，补给 -6。

3. `按静流护送路线绕行`
   - 条件：上午未拒绝检查。
   - 燃料 -12，准点 -1，风险 -12，商会信用 +2。
   - 解锁合规结局分支。

4. `临时回写研究所校准数据`
   - 条件：线索 >= 4 或 Day 2 完整停靠。
   - 线索 +1，风险 -6，波克士稳定度 -8，遥信任 +4。
   - 若波克士稳定度过低，可能引发播报故障。

示例对白：
- 遥：“别问哪条好。问哪条能走完。”
- 波克士：“警告！窗外站牌与数据库不一致。建议列车长相信数据库，也相信那位快把车底盯穿的维修师。”
- 艾略特：“后段有人摔倒？呜哇，怎么偏偏是我这边……我去我去，弗兰你别催！”

### 夜晚：抵达前的选择

剧情：
- 修格里城远处的现实稳定装置亮起。封装货物即将进入交付流程。
- 莉薇娅拿出最终交接单：玩家可以选择完整报告异常、只报告运输结果、或请求延迟交付进行复核。

最终选择：

1. `准点交付，只提交运输结果`
   - 条件：准点 >= 2，货物未严重异常。
   - 结局：商会信用高，奖励最好；莉薇娅后日谈克制，提醒有些异常还会回来。

2. `完整报告异常，接受商会追责`
   - 条件：线索 >= 4，莉薇娅信任 >= 12。
   - 结局：商会信用下降，但修格里维护方获得完整风险记录；莉薇娅后日谈最好。

3. `申请延迟交付，先由遥复核货物`
   - 条件：车况 >= 30，遥信任 >= 12。
   - 结局：准点失败，避免货物过载；遥后日谈最好，列车维修成本上升。

4. `调用波克士应急协议完成交付`
   - 条件：波克士稳定度 >= 45。
   - 结局：压线抵达，但波克士需要检修；若稳定度不足，触发“风暴停驶”失败结局。

5. `停在哨站护送线，等待静流复核`
   - 条件：上午接受检查或选择护送路线。
   - 结局：合规安全，奖励一般；静流认可列车长没有把规程当敌人。

Day 3 结尾钩子：
> 莉薇娅把交接单收进夹板，没有立刻离开。窗外灯光一盏盏掠过，她问：“列车长，明天早上的红茶，还要按今天的浓度吗？”

## 结局后日谈

### 莉薇娅：账本之外

触发高信任：
- 她会把这三天的损失、收益、额外风险都整理好，但最后单独写下一行“不计入账目”的事项：列车长主动听取乘员意见的次数。
- 情绪：温暖、克制、陪伴感强。

低信任：
- 她仍然完成账目，但后日谈偏职业化。
- 她不会责怪玩家，只会提醒“下次请早点告诉我，你打算独自承担什么”。

### 遥：能跑就行

高信任：
- 她允许列车长进入维修车厢看临时旁路，嘴上说“别碰”，但把最安全的位置让出来。
- 她承认这次不是把车修好那么简单，而是让大家都撑到了终点。

低信任：
- 她只提交维修清单，不多解释。
- 如果车况很差，她会直接要求下一次委托前强制整备。

### 波克士：仿生对话系统记录

高稳定度：

低稳定度：
- 它需要检修，饮品速递模块短暂失灵。

### 弗兰与艾略特：护卫记录

高士气 / 护卫事件完成：

低士气：
- 弗兰会直接指出排班太满，艾略特会把“想休息”说得非常响亮；护卫记录显示她们承担了过多临时风险。
