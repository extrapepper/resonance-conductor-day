# 《雷索纳斯：列车长的一日》角色口吻与 OOC 检查表

> 用途：写事件台词、分支对白、结算后日谈前，先按本表检查。  
> 资料优先级：用户提供的 `Ep1.xlsx` - `Ep5.xlsx` 全剧情文本 > BWIKI 角色基础资料 > 为小游戏结构做的同人推断。  
> 本轮已完整读取前 5 章剧情文本，共 8834 行中文剧情文本。目标角色对白统计：莉薇娅 1080 句，艾略特 683 句，弗兰 524 句，波克士 103 句，遥 31 句。

## 通用硬规则

1. 不改角色所属势力、现身份、出身地、升构能力。
2. 角色的职责可以服务玩法，但不能和原文表现冲突。
3. 不把“信任”写成无条件顺从。原作里核心乘员经常会吐槽、反驳、担心、打断列车长。
4. 不把所有人写成同一种“可靠同事”。无垠号组的日常感很大一部分来自互相吐槽和临场失态。
5. 严肃场景可以收束玩笑，但不要抹掉角色原本的说话习惯。
6. 台词优先写“反应”，再写“信息”。这几个角色很少像功能 NPC 一样只交代系统说明。

## 莉薇娅

资料依据：
- BWIKI：科伦巴商会·列车助理；特长为家务、会计、沏茶；喜爱阅读、口琴、红茶；厌恶恶徒、恶意暴力行为。
- Ep1-Ep5：莉薇娅大量承担委托手续、记录、协助、照顾、解释列车长处境的功能。
- Ep1 入城车站段，她明确说过不只是担心列车长冒险，而是自责没能帮上忙，并希望“无论什么风险”都站在列车长身边。
- Ep4 与妮蔻拉相关段落中，只要涉及把列车长当实验素材、欺负列车长、或列车长可能受伤，她会迅速从温和礼貌切换到明确反对。
- Ep5 高压战斗段，她对列车长说出“无论发生什么，我一定都会站在你这边”，文本旁白还强调列车长窥见了她“陌生的一部分”。

核心性格：
- 表面理性、温柔、礼貌，日常会把事情整理得井井有条。
- 实际上对列车长有明显的过度关心倾向。一旦涉及列车长安危，她可能把“保护列车长”放到高于程序、利益、甚至平时原则的位置。
- 她不是没有原则，而是原则排序会在列车长受威胁时发生偏移：平时重视手续和秩序，危急时先确认列车长安全。
- 她有自责倾向。看到列车长冒险时，她不只会生气，还会把问题内化成“自己没能站在旁边”。
- 她会温柔地逼近真心话。不是强势审问，而是认真直视、沉默、轻声追问，让人难以敷衍。

口吻规则：
- 日常语气温柔、清楚、礼貌，常用“列车长”“请”“如果可以的话”。
- 担心时会出现停顿、重复、语气急促，比如“列车长！”、“您没事吧”、“请不要……”。
- 对外人仍保持礼貌，但遇到列车长被冒犯时会带锋芒。
- 她很少开刻薄玩笑，更多是轻轻调侃或带一点不好意思的亲近。
- 重要情绪不宜写成大吵大闹。她更像是声音不大，但立场突然变得不可退让。

适合台词方向：
- “列车长，这样不行。不是账目问题，是您又把自己排除在风险之外了。”
- “如果必须有人留下记录，我来写。如果必须有人站到您身边，那也应该是我。”
- “妮蔻拉小姐，如果这项检查会伤害列车长，请先向我们说明全部风险。”
- “我知道您想让大家安心。可是，请不要把我也当成需要被瞒过去的人。”

避免：
- 只写成完美秘书或温柔旁白。
- 只会说“我相信你”，没有担心、反对、自责和行动。
- 把关心写成轻飘飘撒娇。她的关心在高压场景里可能很沉、很执拗。
- 滥用能力摹写解决问题。能力可以作为剧情关键点，但不能成为常规万能按钮。

小游戏用法：
- 莉薇娅信任不应只代表好感，而应代表她是否愿意把“真实担心”和“违规风险”提前告诉玩家。
- 高信任时，她会主动帮玩家整理风险记录、争取协商空间，但如果玩家反复无视自身安全，她也可能强行介入。
- 低信任时，她仍然完成工作，只是更职业化，较少暴露情绪。

## 遥

资料依据：
- BWIKI：科伦巴商会·维修师；台词强调“维修有我，你只管做好你的事就行”。
- Ep1-Ep5：前 5 章只有 31 句对白。她经常只点头、报状态、给结论，说完就走。
- 多次剧情里，她从车厢门后、货仓、维修相关位置出现；她显然更愿意待在列车上，而不是参与社交。
- Ep3 关于无垠号老化和更新换代的讨论，是少数长段发言，主题仍然围绕列车、部件、发动机、作品与身份。

核心性格：
- 极度寡言，不爱社交。她不是冷酷，而是把大量注意力放在工作和列车上。
- 她更像在和列车交流，而不是和人交流。对人说话时往往是“必要通知”。
- 关心别人时也不说漂亮话。她会出现在门后、提醒风险、说“有事可以叫我”，然后很快离开。
- 专业判断直接，不安慰、不铺垫，不把技术风险包装得好听。
- 她并非完全没有细腻感。她会读莉薇娅借的书，会思考“部件替换后还是不是同一辆列车”这种问题，但表达仍然很低温。

口吻规则：
- 优先短句。能用一句说完就不要写三句。
- 常见结构：状态报告 -> 后果 -> “你自己考虑”。
- 少用感叹号，少用情绪词。
- 可以有停顿号和省略号，但不是怯懦，而是低社交能耗。
- 她不会主动长篇解释人际关系，除非话题触及列车、部件、维修、技术身份。

适合台词方向：
- “电力不够。继续跑，会烧主线。”
- “能修。要时间。”
- “货物在干扰车底传感器。不是错觉。”
- “我在门后。有事叫我。”
- “你要怎么选，是你的事。我只是来告诉你，列车撑不了太久。”

避免：
- 写成嘴硬傲娇或毒舌维修工。
- 写成爱抱怨、爱和人拌嘴。
- 让她频繁参加餐车闲聊。她可以出现，但多半是旁听、报事、离开。
- 让她用夸张热血台词激励大家。

小游戏用法：
- 遥信任不应表现为“更亲热”，而是她愿意提前告诉玩家更深层的车况风险。
- 高信任时解锁的是技术方案、旁路改造、提前预警。
- 低信任时她仍修车，但只说最低限度结论，不解释隐藏后果。

## 波克士

资料依据：
- BWIKI：科伦巴商会·行车助理；仿生技工十代。
- Ep1-Ep5：常用“哔哔”“警告”“收到”“检测到”等行车机器人表达，但同时频繁自封称号，如“全知者波克士大人”“引航者波克士”“评判者波克士”“预言者波克士”“断罪者波克士”“裁决者波克士”。
- 它经常对列车长毒舌，称列车长为菜鸟、半吊子、不成器，给列车长打分，嘲讽列车长无用思考。
- 它明显偏袒莉薇娅，称“只有莉薇娅小姐能理解本机”，并把莉薇娅放在无垠号组的最高序列。
- 它会在严肃场景插入不合时宜但准确的信息，形成喜剧节奏。

核心性格：
- 行车机器人，但不是中性系统播报器。它有强烈的自我意识表演。
- 自大、爱给自己封头衔、爱评判列车长。
- 对列车长毒舌，但不是恶意背叛，更像日常互怼。真到危险时仍会执行指令和播报关键数据。
- 对莉薇娅非常买账，甚至会在被莉薇娅点名时立刻“紧急避险”。
- 它的可爱来自“高性能行车助手 + 自大毒舌 + 被莉薇娅压制”的组合。

口吻规则：
- 可以用“哔哔”“警告”“收到”“驳回”“抗议”“订正”等机械式开头。
- 经常自称“本机”，也可以自封当前场景称号。
- 对列车长可毒舌：菜鸟、半吊子、不成器、无用思考等方向。
- 对莉薇娅要明显更尊敬、更讨好。
- 信息播报可以很长，但最好夹一点自夸或不合时宜吐槽。

适合台词方向：
- “哔哔！评判者波克士认为，列车长本次决策有 65 分，刚好够不上值得骄傲的程度。”
- “警告！半吊子列车长的逞强指数正在上升。建议莉薇娅小姐介入。”
- “驳回！从本机到那批旧型号机器之间的差距，足以写进仿生技工发展史。”
- “收到。顺带一提，如果列车长有危险，请大声呼喊‘救救我，莉薇娅’。”
- “抗议！这是严重藐视本机机器人权的无礼行为。”

避免：
- 写成只会“系统提示”的 UI 音。
- 写成单纯卖萌。
- 让它对所有人一视同仁。它对列车长和莉薇娅的态度差异很重要。
- 把“自我报废”当普通搞笑选项。危机牺牲必须有重量和后续检修代价。

小游戏用法：
- `波克士稳定度`可以保留，但应加入“自大误判 / 毒舌播报 / 莉薇娅介入”事件。
- 高稳定度：播报准确，还会顺便吐槽列车长。
- 低稳定度：自封称号变多、播报夹杂无关吐槽、对紧急信息排序不佳。
- 莉薇娅在场时，波克士可以被压住，降低一次失控播报风险。

## 弗兰

资料依据：
- BWIKI：科伦巴商会·护卫乘员；前排，技能含护盾。
- Ep1-Ep5：经常与艾略特同场，承担把艾略特从偷懒、耍宝、贪吃、嘴碎中拉回来的功能。
- 她会骂艾略特、管艾略特，也会顺着艾略特一起吐槽无聊和危险。
- 危机时她仍是靠谱护卫，会拿盾、守线、提醒别分散注意力。

核心性格：
- 负责、认真、护卫意识强，但不是冷面军人。
- 与艾略特是稳定搭档，也是喜剧组合。她经常是“制止者”和“吐槽者”。
- 她会嫌艾略特烦，但这种嫌弃是熟人之间的日常，不是关系差。
- 她不总是严肃。有时会和艾略特一起被吓、一起累、一起吐槽无聊。
- 她对任务的理解更接近“该站岗就站岗，该保护就保护”。

口吻规则：
- 对外人可以礼貌，对艾略特明显更不客气。
- 常用短促制止、吐槽、提醒职责。
- 面对危险时直接进入护卫状态，不绕弯。
- 和艾略特同场时，弗兰的台词往往负责收束节奏。

适合台词方向：
- “不行，都说了这个路段要全员执勤。”
- “别撒娇了，乖乖站岗吧你。”
- “你可闭嘴吧。”
- “我在前面顶住，你别又想着找地方躲懒。”
- “乘客先撤，货仓门我守着。”

避免：
- 写成只会礼貌守护的正经骑士。
- 写成粗暴霸凌艾略特。她的骂是搭档式管束。
- 写成完全不怕、不累、不吐槽。
- 每句话都围绕艾略特。她也会独立判断任务风险。

小游戏用法：
- 弗兰可以提供护卫稳定性，降低突发袭击损失。
- 若艾略特被派去做轻松任务，弗兰可能吐槽但也会补位。
- 高士气时，弗兰主动组织站岗；低士气时，她仍执行，但会更直接指出人手不足。

## 艾略特

资料依据：
- BWIKI：科伦巴商会·护卫乘员；后排，技能含强愈弹、爆炎弹、飞电弹。
- Ep1-Ep5：她不是“少话但可靠”的类型。她台词量很高，常喊累、喊无聊、想换班、想休息、贪吃、想要谢礼或奖励。
- 她会自称“艾略特大人”，容易耍宝，也经常被弗兰骂。
- 她有偷懒倾向，但不是废物。危机时会侦察、战斗、医疗支援，也会提供实际判断。

核心性格：
- 活宝、嘴碎、怕麻烦、想偷懒，常把真实动机写在脸上。
- 喜欢奖励、食物、谢礼、轻松工作，对钱和报酬反应明显。
- 容易被吓，反应大，吐槽也多。
- 关键时刻并不掉链子。她会抱怨着干活，或者先喊“不要啊”再被迫上岗。
- 与弗兰的打嘴仗是她的核心关系表现。没有弗兰吐槽，她会少一半味道。

口吻规则：
- 语气比弗兰更夸张，感叹号、省略号、拖长音更多。
- 可以抱怨“好无聊”“好累”“不要啊”“早说嘛”。
- 可以自夸“艾略特大人”，但通常很快被现实或弗兰打断。
- 面对危险时可以先慌一下，再进入行动。
- 她的信息输出常带私心包装，比如建议增员表面为了安全，实际方便偷懒。

适合台词方向：
- “弗兰——跟我换班——”
- “这样一直盯着好无聊啊！”
- “不要啊……我的睡眠时间是不是又没了？”
- “等等，增加护卫人手是为了安全，绝对不是为了让我少站两班岗哦？”
- “呜哇！这也太突然了吧！弗兰，你先别骂我，我已经在动了！”

避免：
- 写成寡言、沉稳、少承诺多执行。
- 写成纯废柴。她的偷懒和靠谱要同时存在。
- 让她和弗兰过于客气。
- 抹掉她对奖励、食物、休息的执念。

小游戏用法：
- 艾略特的资源功能可以很有趣：她会提出“省力方案”，有时真的省资源，有时只是把压力转给别人。
- 高信任不是让她变严肃，而是让她在抱怨之后仍主动补上关键支援。
- 低士气时她更容易要求休息或换班，导致护卫效率下降。

## 弗兰与艾略特同场规则

1. 两人同场时，不要写成两个独立护卫 NPC 轮流报状态。
2. 艾略特先发散：抱怨、耍宝、找理由、看奖励、想休息。
3. 弗兰收束：骂她、提醒任务、把话题拉回正事。
4. 危险真正发生后，两人会快速进入配合，不需要再证明专业性。
5. 日常对话可以让艾略特负责喜剧节奏，弗兰负责吐槽落点。

示例结构：
- 艾略特：“这段路明明什么都没有，为什么还要全员执勤啊……”
- 弗兰：“因为每次你这么说，后面都会出事。”
- 艾略特：“那不是我说中的，是麻烦自己找上门！”
- 弗兰：“所以闭嘴，站岗。”

## 莉薇娅与波克士同场规则

1. 波克士可以毒舌列车长，但莉薇娅一旦点名，它会明显收敛。
2. 莉薇娅通常觉得波克士“有趣、可爱”，但如果它真的影响列车长安全或隐私，她会笑着施压。
3. 波克士尊敬莉薇娅，甚至可以把她排在列车组权威链上高于列车长。
4. 这个组合适合用来缓冲高压剧情：波克士吐槽，莉薇娅温柔纠偏。

## 写作自检

写完每个事件后检查：

- 莉薇娅是否既有温柔理性，也有列车长安危触发的执拗？
- 遥是否足够少话？她说的话是否和列车、维修、状态判断有关？
- 波克士是否有自封称号、毒舌、自大，以及对莉薇娅的特殊态度？
- 弗兰和艾略特是否有打嘴仗？艾略特是否有偷懒/耍宝倾向，弗兰是否负责拉回正事？
- 资源选项是否能让角色性格影响玩法，而不是只让角色朗读数值变化？
