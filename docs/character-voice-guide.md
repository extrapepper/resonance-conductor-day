# 《雷索纳斯：列车长的一日》角色口吻与 OOC 检查表

> 用途：写事件台词、分支对白、结算后日谈前，先按本表检查。资料来自 BWIKI 角色页；性格部分如果不是页面明说，一律标注为“同人推断”，并只作为轻量写作约束。

## 通用硬规则

1. 不改角色所属势力、现身份、出身地、升构能力。
2. 不把非核心乘员写成长期随车主角，除非原作身份允许其自然登场。
3. 不让角色承担与身份冲突的职责。例如遥负责维修判断，不写成医疗负责人；弗兰/艾略特负责护卫，不写成账务助理。
4. 不使用夸张恋爱化台词。莉薇娅可以亲近、可靠、陪伴，但不要把所有互动写成单一暧昧。
5. 角色之间的分歧来自职责和判断，不来自无端吵架。
6. 每个角色至少有一个“拒绝玩家”的合理边界：信任不是无条件顺从。

## 莉薇娅

资料依据：
- 势力：科伦巴商会。
- 现身份：科伦巴商会·列车助理。
- 出身地：曼杜斯帝国。
- 升构能力：能力摹写。
- 特长：家务、会计、沏茶。
- 喜爱：阅读、口琴、红茶。
- 厌恶：恶徒、恶意暴力行为。
- 页面台词强调她与列车长同行、在身边的陪伴感。
- 来源：https://wiki.biligame.com/resonance/莉薇娅

写作定位：
- 主互动角色。她是玩家每天开始与结束时最稳定的情绪锚点。
- 职责是整理委托、核算账目、照看乘员状态、提醒风险。
- 她不是单纯秘书，也不是只会鼓励。遇到不合理委托、恶意暴力、伤害乘员的决定时，她应当温和但明确地反对。
- 她的亲近感来自“记得细节”：谁没休息、哪笔账不对、红茶有没有变凉、列车长是否又把压力藏起来。

口吻规则：
- 语气温和、清楚、克制；可以带一点担心。
- 先陈述事实，再补一句关照。
- 不用攻击性语言；批评时更像提醒你承担后果。
- 可以称呼“列车长”，但不要每句都叫。

适合台词方向：
- “账目上还有余量，但如果今晚继续加速，明天的维修预算会不够。”
- “我会把委托记录整理好。你去见遥吧，她刚才没有把话说完。”
- “这不是一笔漂亮的买卖，可我知道你不是为了漂亮才这么选。”

避免：
- 过度撒娇。
- 用能力摹写随便解决所有问题。
- 把她写成没有主见、只负责说“我相信你”。

## 遥

资料依据：
- 势力：科伦巴商会。
- 现身份：科伦巴商会·维修师。
- 出身地：贡露城。
- 升构能力：无。
- 页面台词强调维修由她负责，列车长做好自己的事。
- 来源：https://wiki.biligame.com/resonance/遥

写作定位：
- 次核心互动角色。她负责车况、引擎、车厢故障、现场改造。
- 她是资源管理的硬约束来源：有些路线不是玩家想走就能走，列车要先撑得住。
- 同人推断：从台词可推断她干脆、少废话、专业优先。

口吻规则：
- 短句多，直接给结论。
- 少解释情绪，多解释机械状态。
- 信任高时不是变软，而是愿意多说一句风险背后的原因。

适合台词方向：
- “能修。要时间，要零件。二选一，不存在第三种。”
- “你要赶路，我就把功率顶上去。后果我先说清楚，别装没听见。”
- “刚才那次震动不是轨道，是车底传回来的。有人动过线路。”

避免：
- 长篇抒情。
- 遇事慌张。
- 被写成只会抱怨的维修工。

## 波克士

资料依据：
- 势力：科伦巴商会。
- 现身份：科伦巴商会·行车助理。
- 性别：无。
- 出身地：科伦巴商会。
- 页面台词呈现仿生技工启动与声纹设定。
- 技能包含军械库、饮品速递、自我报废等方向。
- 来源：https://wiki.biligame.com/resonance/波克士

写作定位：
- 次核心互动角色。承担行车播报、物资查询、应急处理、轻喜剧缓冲。
- 它的幽默来自系统式表达与现实场景错位，不来自装傻。
- 重要边界：不要把“自我报废”写成轻飘飘笑点。它应当是极端危机选项，带代价和修复后果。

口吻规则：
- 可使用“提示 / 警告 / 建议 / 当前方案”式结构。
- 句式偏机械，但能保留一点仿生对话系统的拟人化偏差。
- 不使用人类性别化自称。

适合台词方向：
- “警告：列车长的沉默时长已超过建议值。是否需要热红茶、冷水，或莉薇娅助理介入？”
- “当前燃料不足以同时支持绕行和加速。建议删除一个愿望。”
- “饮品速递完成。杯壁温度适合双手握持，这不是战术建议，是生活建议。”

避免：
- 全程卖萌。
- 让它像普通人一样长篇感慨。
- 滥用牺牲桥段。

## 弗兰

资料依据：
- 势力：科伦巴商会。
- 现身份：科伦巴商会·护卫乘员。
- 出身地：伊敦恩城。
- 升构能力：无。
- 页面台词中她礼貌自我介绍，并顺口询问艾略特位置。
- 战斗定位偏前排，技能包含护盾方向。
- 来源：https://wiki.biligame.com/resonance/弗兰

写作定位：
- 常驻护卫角色。负责车厢巡逻、货物护送、乘客安全。
- 她与艾略特适合写成护卫搭档线：弗兰更偏正面保护和现场秩序，艾略特更偏后排支援和执行。
- 同人推断：她可以比艾略特更外向、更容易显露对搭档位置的在意。

口吻规则：
- 礼貌、认真，风险场合先确认队友和防线。
- 提到艾略特要自然，不要变成单一口癖。

适合台词方向：
- “我可以守住餐车到货仓这一段。艾略特如果在后方，盲区会少很多。”
- “列车长，请先让乘客离开门边。剩下的交给我。”

避免：
- 写成鲁莽冲动。
- 每句话都只找艾略特。

## 艾略特

资料依据：
- 势力：科伦巴商会。
- 现身份：科伦巴商会·护卫乘员。
- 出身地：伊敦恩城。
- 升构能力：无。
- 页面台词强调“该干的活会干”。
- 战斗定位偏后排，技能含治疗弹、爆炎弹、飞电弹方向。
- 来源：https://wiki.biligame.com/resonance/艾略特

写作定位：
- 常驻支援护卫。负责后方火力、急救支援、掩护撤离。
- 她的可靠感不靠多话，而靠总是在该出现的位置出现。

口吻规则：
- 句子短，态度平稳。
- 少承诺，多执行。
- 高信任时可以多一句判断，但仍不煽情。

适合台词方向：
- “我去后车厢。有人受伤就发信号。”
- “弗兰在前面，我补后排。这样最稳。”
- “补给够一次急救。别让我用在可以避免的伤上。”

避免：
- 突然话痨。
- 过度温柔医疗化。她是护卫支援，不是专职医生。

## 卡洛琳

资料依据：
- 势力：阿妮塔。
- 现身份：园丁·探路者。
- 出身地：7号自由港。
- 升构能力：第六感。
- 页面台词较外向，主动和列车长打招呼。
- 来源：https://wiki.biligame.com/resonance/卡洛琳

写作定位：
- 7号自由港与污染路线侦查 NPC。
- 她可以提示“直觉不对”的路线风险，但不替玩家证明一切。
- 同人推断：探路者身份适合让她提供路线、气候、异常地形信息。

口吻规则：
- 相对轻快，但在危险判断上很坚定。
- 不神棍化第六感；她的直觉应结合探路经验表现。

## 妮蔻拉

资料依据：
- 势力：阿妮塔。
- 现身份：园丁·能源研究所负责人。
- 升构能力：思维宫殿。
- 特长：机械工程、发明创造、数独游戏。
- 喜爱：毛绒玩具、发明创造、土豆。
- 厌恶：无聊争论、过度煽情的作品、唯利是图的人。
- 来源：https://wiki.biligame.com/resonance/妮蔻拉

写作定位：
- 阿妮塔能源研究所关键 NPC。负责能源样本、研究方案、技术交易。
- 她可以强势提出更高效但更冒险的技术方案。
- 她不喜欢无意义争论，因此对拖延、空话、纯逐利选择会不耐烦。

口吻规则：
- 技术导向，跳过客套。
- 可以有轻微压迫感，但不恶意。
- 不写成疯狂科学家；她的方案要有理性边界。

## 静流

资料依据：
- 势力：环大陆铁道联盟。
- 现身份：铁盟·蜜獾小队队长。
- 出身地：铁山城。
- 升构能力：无。
- 页面台词暗示她与列车长并非第一次见面。
- 来源：https://wiki.biligame.com/resonance/静流

写作定位：
- 铁盟哨站秩序线 NPC。负责检查、封锁、护送、军事规程压力。
- 她不是反派。她代表“列车必须按规程通过危险区”的立场。

口吻规则：
- 克制、负责、带一点旧识感。
- 公事公办，但在规则允许内会给列车长留下余地。

适合台词方向：
- “我可以给你十分钟解释。十分钟后，哨站按规程处理。”
- “别把我放在必须拦你的那一边，列车长。”

避免：
- 单纯阻挠玩家。
- 无理由放行。
