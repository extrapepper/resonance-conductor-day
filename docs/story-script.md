# 《雷索纳斯：列车长的一日》台本重构案（废案）

> 状态：废弃。本文包含“阿莉娅 / 米卡 / 诺艾尔”等原创占位角色，不适合作为明确《雷索纳斯》同人项目的设定基础。
> 后续台本请以 `docs/canon-casting-notes.md` 为准，使用原作乘员、原作势力和原作站点。

## 设计目标

第一版玩法要从“所有选项都是加数值”改成“每个时段都是取舍”。

玩家扮演列车长，在 7 日短途值乘中处理一件逐渐失控的委托。剧情体验接近视觉小说 + 日程管理：固定横屏舞台、场景切换、角色立绘互动、底部对话框推进。玩家每天只有有限行动次数，无法同时照顾乘员、修车、调查异常、赶路和救助他人。

核心情绪不是末世大拯救，而是：一辆列车上，大家都在硬撑；列车长的每个选择都会决定谁愿意把真实想法说出来。

## 核心资源

- `时间`：每天 3 个时段。主线事件会占用时段，错过后只能进入补救线。
- `车况`：低于 35 会触发故障，低于 20 会强制消耗一个时段维修。
- `燃料`：用于赶路、绕行、加速脱离危险。燃料不足会错过准点结局。
- `补给`：用于治疗、安抚乘客、救助路人。补给不足会降低士气或牺牲支线收益。
- `士气`：影响乘员是否主动提出方案。低于 30 时部分角色选项锁定。
- `疲劳`：高疲劳会让行动效果变差；高于 75 时夜晚不能调查，只能休息。
- `线索`：决定是否看清主线真相。线索不足只能走表面结局。
- `风险`：绕行、隐藏委托、接纳陌生人会提高风险。高风险引来追踪或袭击。
- `信任`：阿莉娅、米卡、诺艾尔各自独立。信任不是单纯好感，而是能否解锁“把事情交给她处理”的分支。

资源方向要有正负：

- 赶路：燃料 -，疲劳 +，准点进度 +。
- 维修：时间 -，车况 +，米卡信任 +，但可能错过角色事件。
- 救助：补给 -，风险 +，士气 +，诺艾尔信任 +。
- 调查：时间 -，线索 +，风险 +，可能降低委托方信任。
- 安抚：时间 -，士气 +，对应角色信任 +，但车况/燃料不改善。

## 主线概要

章节名：`雾灯短途`

表面委托是把一只密封货箱送到终点补给站。委托方要求准点、不开箱、不绕路。第一天夜里，列车收到一段来自废弃支线站的求救信号。第二天起，货箱与求救信号都出现异常共振。玩家会逐渐发现：货箱不是普通物资，而是一枚用于稳定“信标塔”的核心；如果准点送达，终点站能恢复通讯，但废弃支线站的人可能被放弃。如果绕行救人，终点站会延迟恢复，列车也可能被委托方追责。

主线的核心问题：

> 你是列车长。你要把列车开向合同上的终点，还是开向无线电里那个越来越微弱的声音？

## 主要角色线

### 阿莉娅：护卫线

外显：冷静、强硬、总是先挡在别人前面。

隐藏矛盾：她过去护送过一趟“准点优先”的列车，那次为了不延误，她听从命令没有停靠求救站点。后来她知道那里有人活着等过救援。

分支功能：

- 高信任：阿莉娅愿意组织乘员轮班护卫，降低高风险事件损失。
- 中信任：她只执行命令，不主动提出绕行方案。
- 低信任：高风险时她会建议抛弃支线救援，保护列车优先。

关键选择：

- 告诉她“这次由我承担责任”：阿莉娅信任 +，风险 +。
- 告诉她“先按合同执行”：风险 -，阿莉娅信任 -，准点进度 +。

### 米卡：维修线

外显：嘴硬、爱拆东西、比起人更擅长听懂机器。

隐藏矛盾：她发现货箱的共振频率会损伤列车主引擎，但如果拆开检查就违反委托。她不想再次因为“擅自判断”被认为不可靠。

分支功能：

- 高信任：米卡可在不打开货箱的情况下做旁路稳定器，车况损耗减半。
- 中信任：她能修车，但需要消耗更多时间。
- 低信任：她只修表面故障，后期会触发一次强制停驶。

关键选择：

- 允许米卡拆封外层检查：线索 +，车况 +，风险 +，准点进度 -。
- 阻止她拆封：委托风险 -，米卡信任 -，后续车况持续 -。

### 诺艾尔：医疗线

外显：温柔、细心、习惯先照顾别人。

隐藏矛盾：她在求救信号里听出了医疗编码，判断支线站不是诱饵，而是隔离病患在求救。她害怕自己判断错，导致整车人暴露于感染风险。

分支功能：

- 高信任：诺艾尔可建立临时隔离区，允许救助支线站幸存者但消耗补给。
- 中信任：可以救一个关键 NPC，但无法救全部。
- 低信任：她会建议不要接触未知病患，支线救援关闭。

关键选择：

- 支持她准备隔离区：补给 -，疲劳 +，诺艾尔信任 +，救援线开启。
- 要求她节省物资：补给 +，士气 -，诺艾尔信任 -。

## 7 日主线台本

### Day 1：密封货箱

主场景：休息车厢 / 货仓 / 驾驶室

主线事件：

- 委托方交付密封货箱，要求准点送达，不得开箱。
- 夜晚收到废弃支线站的求救噪声，只有一小段医疗编码能被识别。

时段事件：

- 上午：启程检查。
  - `按合同清点货箱`：准点进度 +，线索 0，米卡信任 -。
  - `让米卡额外扫描货箱`：线索 +1，车况 -，风险 +。
- 下午：乘员适应。
  - `巡逻货仓`：阿莉娅信任 +，风险 -。
  - `去餐车安抚乘员`：士气 +，时间占用，车况不变。
- 夜晚：求救信号。
  - `记录信号但不改变路线`：准点进度 +，诺艾尔信任 -。
  - `追踪信号来源`：线索 +1，燃料 -，风险 +。

Day 1 结尾钩子：

> 货箱在午夜轻轻震了一下。不是撞击，更像它听见了什么。

### Day 2：共振

主场景：驾驶室 / 医疗车厢 / 货仓

主线事件：

- 列车经过风暴边缘，货箱开始影响仪表。
- 诺艾尔确认求救信号里有隔离病患的医疗编码。

关键分支：

- 若 Day 1 追踪信号：可选择临时改道。
- 若没追踪：只能听到更弱的求救声，线索不足。

时段事件：

- 上午：仪表异常。
  - `强行维持速度`：准点进度 +，车况 -8，疲劳 +。
  - `降速排查`：车况 +，准点进度 -，米卡信任 +。
- 下午：医疗判断。
  - `相信诺艾尔，准备隔离区`：补给 -10，诺艾尔信任 +，救援线开启。
  - `要求继续观察`：补给不变，诺艾尔信任 -，士气 -。
- 夜晚：阿莉娅巡逻发现货箱封条松动。
  - `重新封存`：风险 -，线索 0。
  - `检查封条内侧`：线索 +1，风险 +，阿莉娅信任取决于是否提前告知她。

Day 2 结尾钩子：

> 封条内侧有一行小字：如果它开始回应，请不要让它独自抵达。

### Day 3：废弃支线站

主场景：车窗外支线站 / 驾驶室 / 休息车厢

主线事件：

- 列车接近可绕行节点。
- 乘员第一次明确分歧：准点派、救援派、谨慎派。

路线大选择：

- `继续主线铁路`：准点进度 +2，风险 -，救援线关闭或变为补救线。
- `驶入支线站`：燃料 -15，风险 +15，救援线开启，准点进度 -2。
- `停车派无人机侦查`：时间 -，线索 +，燃料 -5，取决于米卡信任是否减少车况损失。

角色冲突：

- 阿莉娅担心支线是诱饵。
- 诺艾尔坚持信号是真人。
- 米卡认为货箱正在“回答”支线站。

Day 3 结尾钩子：

> 你看见站台灯牌亮了一瞬。上面不是站名，而是你这辆列车的编号。

### Day 4：车上多了一个人

主场景：医疗车厢 / 休息车厢 / 货仓

主线事件：

- 如果进入支线站：救回一名失语幸存者“灰鸽”。他携带终点站信标塔的旧钥匙。
- 如果没进入支线站：列车上发现一段被远程写入的旧钥匙数据，但信息不完整。

分支差异：

- 救人路线：补给持续下降，风险上升，但线索更多。
- 不救路线：资源稳定，但真相缺口变大。

时段事件：

- `让诺艾尔治疗灰鸽`：补给 -，诺艾尔信任 +，线索 +。
- `让阿莉娅审问灰鸽`：风险 -，阿莉娅信任 +，士气 -。
- `让米卡读取旧钥匙`：车况 -，米卡信任 +，线索 +。
- `让灰鸽休息`：士气 +，线索延后。

Day 4 结尾钩子：

> 灰鸽终于写下第一句话：终点站不是要启动信标，是要关掉它。

### Day 5：委托方追踪

主场景：驾驶室 / 货仓 / 车顶检修口

主线事件：

- 委托方发现列车偏离协议，发来强制接管请求。
- 玩家必须选择是否切断远程链路。

关键选择：

- `接受接管`：风险 -，准点进度 +，线索线大幅关闭，乘员信任 -。
- `切断链路`：风险 +，燃料 -，全员信任取决于前期关系。
- `伪装信号`：需要米卡高信任或线索 >= 4；风险小幅 +，保留路线自由。

角色派生：

- 阿莉娅高信任：她会主动承担护卫，抵消一次追踪损失。
- 米卡高信任：她能做伪装信号。
- 诺艾尔高信任：她能让乘员相信你不是任性冒险，士气不降。

Day 5 结尾钩子：

> 远方轨道上出现另一列没有车灯的列车，像一条贴着地面滑来的影子。

### Day 6：风暴眼

主场景：全车广播 / 驾驶室 / 各角色专属场景

主线事件：

- 风暴袭来，玩家必须做最终准备。
- 这是角色线结算日前的最后一次补救。

三类准备：

- `抢修主引擎`：车况 +，米卡信任 +，疲劳 +，错过安抚。
- `组织全员避险`：士气 +，阿莉娅信任 +，准点进度 -。
- `建立隔离与救护区`：补给 -，诺艾尔信任 +，救援结局条件 +。
- `调查货箱核心`：线索 +，风险 +，若疲劳高则失败。

Day 6 夜晚角色独白：

- 阿莉娅：问你如果救援失败，是否后悔。
- 米卡：承认列车撑不到两边都完美。
- 诺艾尔：说她最怕的不是死人，而是大家习惯“不去听见”。

Day 6 结尾钩子：

> 货箱终于打开了一条缝。里面没有武器，只有一盏还亮着的雾灯。

### Day 7：抵达或偏航

主场景：终点站 / 支线信标塔 / 列车休息室

最终选择根据资源与线索开放：

- `准点交付货箱`
  - 条件：准点进度高，车况 >= 25。
  - 结果：终点站恢复表面秩序，但支线站真相被压下。
- `公开信标真相`
  - 条件：线索 >= 5，至少 2 名乘员信任 >= 45。
  - 结果：延误，委托失败，但乘员站在你这边。
- `改道启动旧信标`
  - 条件：燃料 >= 20，车况 >= 40，诺艾尔信任 >= 45，米卡信任 >= 45。
  - 结果：救援范围扩大，终点站延迟恢复。
- `折中交涉`
  - 条件：线索 >= 3，阿莉娅信任 >= 45，士气 >= 45。
  - 结果：交出部分核心数据，保住列车和部分救援。
- `被迫停驶`
  - 条件：车况 < 20 或疲劳 > 90。
  - 结果：无论立场如何，列车无法抵达，只能等待救援。

## 结局列表

### A. 准点抵达

玩家遵守合同，货箱准点送达。列车获得报酬，终点站恢复通讯。乘员表面平安，但支线站求救再也没有响起。

适合资源状态：

- 准点进度高
- 风险低
- 线索低

情绪：安全，但有余味。

### B. 雾灯公开

玩家收集足够线索，在终点站公开委托方隐瞒支线站的事实。列车被追责，但乘员共同作证。

适合资源状态：

- 线索高
- 至少 2 名角色信任高
- 士气中高

情绪：不完美但诚实。

### C. 支线救援

玩家改道启动旧信标，救下支线站幸存者。终点站延迟恢复，列车燃料几乎耗尽，但车上没有人后悔。

适合资源状态：

- 诺艾尔、米卡信任高
- 燃料/车况足够
- 补给曾投入救援

情绪：温暖、代价明确。

### D. 护送折中

玩家用部分线索与委托方谈判，既交付货箱，也保留救援坐标。不是大胜利，但列车继续获得运行许可。

适合资源状态：

- 阿莉娅信任高
- 线索中等
- 风险没有爆表

情绪：现实、克制、适合普通路线。

### E. 风暴停驶

资源管理失败，列车在风暴眼前停驶。结局不直接惩罚玩家，而是让乘员根据关系状态陪你收拾残局。

触发：

- 车况过低
- 疲劳过高
- 燃料不足且准点/救援都失败

情绪：失败但仍有陪伴。

## 分支触发规则

- 线索 >= 3：玩家知道货箱与信标有关。
- 线索 >= 5：玩家知道终点站将关闭旧信标。
- 阿莉娅信任 >= 45：高风险事件可由她抵消一次损失。
- 米卡信任 >= 45：可伪装委托方追踪信号。
- 诺艾尔信任 >= 45：可安全接纳支线站幸存者。
- 士气 < 30：角色不会主动提出冒险方案。
- 疲劳 > 75：夜晚调查失败，强制休息。
- 车况 < 35：每日开始前触发故障检查。

## 第一阶段落地建议

下一次实现时，先不一次性写完 7 天全部文本。建议先做：

1. 把资源系统扩成 `车况 / 燃料 / 补给 / 士气 / 疲劳 / 线索 / 风险 / 准点进度`。
2. 把行动从固定 5 个地点，改成“每天可用行动池”，每个行动有正负成本。
3. 实装 Day 1 - Day 3，形成第一个关键分歧：继续主线、驶入支线、无人机侦查。
4. 增加条件选项锁定提示，例如“需要米卡信任 35”或“燃料不足”。
5. 把结算从单一评分改成“当前路线预览”，先提示玩家已进入哪条倾向。

这样玩家会在前 10 分钟内感到：每个选项都在放弃另一个可能性。
