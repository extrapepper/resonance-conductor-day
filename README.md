# 雷索纳斯：列车长的一日

一个《雷索纳斯》方向的非商业同人网页小游戏原型。第一版聚焦列车长与乘员的日常互动，而不是复刻原作跑商或战斗。

## 运行方式

直接用浏览器打开 `index.html` 即可运行。项目不需要构建工具、后端服务或第三方依赖。

## 第一版内容

- 3 天短途执勤。
- 每天 3 个时段：上午、下午、夜晚。
- 5 个行动地点：驾驶室、餐车、医疗车厢、休息室、货仓。
- 3 名占位乘员：护卫、维修、医疗。
- 轻压力数值：士气、车况、疲劳、乘员信任。
- 第 3 天夜晚后生成旅程结算和乘员后日谈。

## 素材替换

当前版本使用原创占位视觉。后续可以将用户提供或授权可用的素材放入：

- `assets/characters/`：角色立绘或头像。
- `assets/bg/`：列车、车厢或站台背景。

建议角色图片使用竖向 PNG/WebP，背景使用 16:9 横图。替换素材后再在 `index.html` 或 `app.js` 中引用。
