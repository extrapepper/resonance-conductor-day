# 雷索纳斯：列车长的一日

一个《雷索纳斯》方向的非商业同人网页小游戏原型。第一版聚焦列车长与乘员的日常互动，而不是复刻原作跑商或战斗。

## 运行方式

直接用浏览器打开 `index.html` 即可运行。项目不需要构建工具、后端服务或第三方依赖。

## 第一版内容

- 7 天短途执勤主线。
- 每天 3 个时段：上午、下午、夜晚。
- 5 个行动地点：驾驶室、餐车、医疗车厢、休息室、货仓。
- 核心互动乘员：莉薇娅、遥、波克士、弗兰、艾略特。
- ADV/galgame 式逐句对话框，点击对话框或按空格/回车推进。
- 轻压力数值：士气、车况、疲劳、燃料、补给、准点、风险、线索、乘员信任。
- 第 7 天夜晚后根据选择生成旅程结算和乘员后日谈。
- 所有中文剧情、开场、选项结果和乘员长对话集中在 `data/story.zh-CN.js`，方便后续修改与多语言拆分。

## 素材替换

当前版本的角色立绘来自 BWIKI 角色资料页下载，场景背景来自 BWIKI「过场图」页面，用于本地非商业同人原型预览。后续可以将用户提供或授权可用的素材放入：

- `assets/characters/`：角色立绘。
- `assets/avatars/`：左侧 HUD 使用的角色头像。
- `assets/bg/`：列车、车厢或站台背景。当前使用 WebP 以减少 GitHub Pages 首屏加载时间。

建议角色立绘使用竖向 PNG/WebP，头像使用 1:1 方图，背景使用 16:9 或接近 16:9 的横图。替换角色素材后，在 `data/story.zh-CN.js` 的 `characterScripts` 中修改对应 `sprite` 与 `avatar` 路径；替换场景背景时，修改同文件里的 `backgrounds` 映射即可。
